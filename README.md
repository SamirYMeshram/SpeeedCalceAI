# SpeedCalc AI

Java + XML native Android speed math trainer.

## Open
1. Open this folder in Android Studio.
2. Let Gradle sync.
3. Run the app on an emulator or Android device.

## Included now
- Splash, login, register
- MainActivity with bottom navigation
- Practice, Revision, Quiz, Dashboard, Account fragments
- Liquid-glass inspired dark UI
- Practice setup bottom sheet
- PracticeActivity with direct input and MCQ modes
- Addition, subtraction, multiplication, division, simplification, quadratic, complexity generators
- Result screen
- Room attempt history and question review
- MPAndroidChart dashboard
- Firebase dependencies prepared for cloud phase

## Firebase/Grok safety
Do not put a Grok API key in the Android app. Use:
Android app -> backend / Firebase Function -> Grok API -> Android app
